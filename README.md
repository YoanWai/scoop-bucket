# scoop-bucket

Scoop bucket for [agent-manager](https://github.com/YoanWai/agent-manager).

```powershell
scoop bucket add yoanwai https://github.com/YoanWai/scoop-bucket
scoop install yoanwai/agent-manager
```

`agent-manager` depends on [psmux](https://github.com/psmux/psmux), which Scoop installs from the main bucket.
